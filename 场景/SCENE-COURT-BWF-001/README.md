## 锁定尺寸

| 项目 | 尺寸 |
|---|---:|
| 全场长度 | `13.40 m` |
| 双打宽度 | `6.10 m` |
| 单打宽度 | `5.18 m` |
| 所有场线宽度 | `0.040 m` |
| 短发球线距球网 | `1.98 m` |
| 双打后发球线距底线 | `0.76 m` |
| 网柱高度 | `1.55 m` |
| 网中央高度 | `1.524 m` |

尺寸按场线外缘定义；代码使用场线中心坐标补偿 `20 mm` 半线宽。完整场线包括双打外边线、
单打边线、两侧底线、短发球线、双打后发球线和中央发球线。

## 全局使用规则

- 所有新 Blender 球场必须调用本标准几何，不得凭画面需要缩放场地或随机增删场线。
- 角色站立身高按约 `1.68—1.75 m` 代理；成人球拍总长固定约 `0.675 m`。
- 单打对拉时双方必须分别位于球网两侧、各自半场内。若两人落在同一半场，立即判定失败。
- 人、球拍和羽毛球不得穿过网柱或球网实体；允许击球后的球拍随挥越过网面，但初始触球点必须在击球者一侧。

# SHOT-006｜杀球钉地与错愕｜5 秒分镜脚本

## 绑定

- 分镜版本：`BOARD-v001`
- 状态：`KEYFRAMES-TO-GENERATE`
- 主角：`CHAR-001 / 铁蛋 / v003 / LOCKED`
- 对手：`CHAR-002 / 橙超 / v001 / OFFSCREEN-AFTER-IMPACT`
- 表情：`EXP-003 / 错愕 / E4`
- 场景：`SCENE-HALL-001 / ENV-v001 / LOCKED`
- 风格：`NEON-SHUTTLE-CATS / STYLE-v002`

## 时间轴

| 时间 | 画面与动作 | 镜头 | 声音 |
|---|---|---|---|
| 0.00—0.75s | 承接 SHOT-005 的陡峭球路，正常大小羽毛球以球头先触地，钉在铁蛋半场白线内侧；铁蛋鞋尖晚半拍急停进入边缘 | `COURT-FLOOR`，距地 5—10 cm，固定极近特写 | 尖锐风声、短促球头落地声、急停鞋声 |
| 0.75s | 一帧硬切到铁蛋脸部，不推近、不变焦 | 正面偏 3/4 大特写 | 球馆声瞬间抽空 |
| 0.75—1.15s | 中立严肃脸快速进入错愕，耳朵先失衡、瞳孔骤缩 | 固定大特写 | 短吸气 |
| 1.15—4.10s | `EXP-003 E4` 峰值：眼睛放大、嘴成小圆、双耳不对称、胡须外张，两侧甩出夸张大汗珠；保持短暂停顿 | 背景简化为冷青/酸黄放射色块，角色身份锚点清楚 | 汗珠甩出声，远处压低惊呼 |
| 4.10—5.00s | 表情轻微回弹但仍错愕；汗珠继续飞离画面，球馆环境声恢复 | 镜头仍固定 | 环境声回归 |

## 关键帧

1. `KF01 / 0.35s`：羽毛球球头先触地，真实体积、白线尺度稳定、铁蛋脚尖入画。
2. `KF02 / 0.95s`：铁蛋从 E0 进入错愕，至少保留额头 M 纹、眼周纹、粉鼻和耳形。
3. `KF03 / 2.10s`：`EXP-003 E4` 峰值与大汗珠。
4. `KF04 / 4.55s`：轻微回弹，仍能读出错愕，汗珠与脸分离。

## 硬约束

- 球必须在铁蛋所在半场落地，球头先触地；不得变成网球、能量球或球头朝上漂浮。
- `SHOT-005` 的羽球离场方向与本镜入场方向一致。
- 错愕夸张只改变表情比例，不改变铁蛋物种、脸型、毛纹、服装、右腕手表和装备身份。
- 只有 `0.75s` 一次硬切；禁止从地板镜头平滑推到脸部。

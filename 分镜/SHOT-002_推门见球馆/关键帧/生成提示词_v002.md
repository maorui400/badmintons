# SHOT-002｜关键帧组提示词 v002

生成一张 16:9 横向 2×2 联系表，无文字、无编号；左上、右上、左下为三阶段，右下纯深墨蓝。

- A：门外背后三分之四约35度俯视。左手完整包握球拍，球拍沿左腿外侧；右掌接触右侧门扇。
- B：右肩、肘、腕自然发力，右手把门扇推向馆内；左手仍握同一支球拍，球拍不越过身体中线。
- C：双门扇已向球馆内部打开，馆内多块场地纵深展开；左手仍持拍，右臂放松。

三格固定 `CHAR-001 v003 / COST-B / SHOE-001 / RACKET-001 / STYLE-v002`。黑表只在右腕。禁止门外开、球拍换手/复制/穿模、左右镜像、腕表换边、场地漂移、文字与 Logo。

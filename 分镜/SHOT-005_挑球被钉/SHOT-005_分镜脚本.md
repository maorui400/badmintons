# SHOT-005｜橙超完整跳杀｜5 秒分镜脚本

## 绑定

- 分镜版本：`BOARD-v002 / ACTION-REBUILD-v001`
- 状态：`SIX-KEYFRAMES-TO-GENERATE`
- 攻方：`CHAR-002 / 橙超 / v001 / LOCKED`
- 守方：`CHAR-001 / 铁蛋 / v003 / LOCKED`
- 动作：`ACTION-SMASH-v001 / SMASH-P1—P6`
- 场景：`SCENE-HALL-001 / ENV-v001 / LOCKED`
- 风格：`NEON-SHUTTLE-CATS / STYLE-v002`
- 画幅：`16:9 / 1280×720 / 24 fps`

## 镜头目的

保留原橙超杀球镜头的背后三分之四低仰角和双方场区关系，把原先挤在一个关键帧中的
跳杀拆成六个可验证阶段。铁蛋的挑球已在上一动作节拍发生，本镜从羽毛球升到橙超头顶
前上方开始；钉地和错愕移到 `SHOT-006`。

## 固定机位

- 相机位于橙超后场身后偏左、距地约 35 厘米，朝球网和铁蛋远场看。
- `BODY-NEAR + COURT-FLOOR + P3`；低仰角，但不使用鱼眼。
- 橙超占画面高度约 65%—78%，球网横穿中远景；铁蛋始终可见于网另一侧场内。
- 六帧相机、地平线、主消失点、网柱、灯光和双方左右位置全部锁定；只允许角色动作变化。

## 六关键帧时间轴

| 时间 | 帧 | 动作 | 画面检查点 |
|---|---|---|---|
| 0.20s | `KF01 / P1` | 橙超到位压缩，右脚略后、屈膝侧身；左手追踪上方羽球，右肘屈曲后撤 | 球在右肩前上方；右臂没有伸直；铁蛋在远场 |
| 0.85s | `KF02 / P2` | 踝膝髋蹬伸，双脚刚离地，骨盆开始旋转 | 左手仍高；右肘高、拍头滞后；起跳来源清楚 |
| 1.55s | `KF03 / P3` | 空中弓形预拉伸，胸廓打开，双腿保持平衡 | 左臂开始下收；右肩外旋、屈肘，拍头在头后 |
| 2.25s | `KF04 / P4` | 骨盆—胸廓—肩—肘—前臂依次加速，在身体前上方击球 | 右肘先行、临近触球才展开；拍面朝铁蛋近侧落点 |
| 3.15s | `KF05 / P5` | 球拍向左下跨体随挥，躯干旋转前屈，橙超下降 | 羽球已离拍形成陡线；禁止冻结或回抽 |
| 4.35s | `KF06 / P6` | 脚落到重心附近，髋膝屈曲吸震并开始回位 | 落地连续、头看远场；铁蛋仍在对面，镜头无漂移 |

## 声音与衔接

- 前段：鞋底蹬地、衣料和短促呼吸。
- `2.25s`：球拍破风后接尖锐触球爆点。
- 后段：羽球高速远去、橙超落地鞋声。
- 末帧以羽毛球飞出画面下方作为 `SHOT-006` 钉地镜头的动作匹配点。

## 动作与连续性否决项

- 完整遵循 `动作/杀球/杀球动作规范.md`；任一动作否决项触发则整组六帧重做。
- 六帧只能有一个橙超、一把右手球拍和一只羽毛球；不得跨帧换手或变换装备。
- 铁蛋不得消失、站到同一半场或出现在网外；球网与双方场区不能镜像。
- `KF03` 不能把“弓形引拍”画成右臂笔直朝天；`KF04` 才进入近伸展触球。
- 相机禁止绕人、推拉、升降；该镜头的张力来自连续人体动力链，不来自摄影机运动。

# EP02-SHOT-001 关键帧提示词 v002

生成 3×2 六格连续关键帧：铁蛋底线背后固定机位的橙超起跳杀球、橙超高点击球、铁蛋右手短引拍卸力挡放；随后硬切网带超近景的羽毛球接近、擦滚网带、落入橙超前场。绑定 `CHAR-001 v003 / CHAR-002 v001 / ACTION-SMASH-v001 / ACTION-BLOCK-NET-v001 / SCENE-HALL-001`。

铁蛋背对镜头时，画面右侧必须是他的解剖学右手，球拍和闭合黑表均在该侧；橙超面对镜头时，画面左侧是其右手持拍臂。保持单一球、球头领先、真实羽毛裙、正确网高与重力。使用 `NEON-SHUTTLE-CATS / STYLE-v002`，禁止换手、镜像毛纹、多球、能量球、错误关节和跨轴。

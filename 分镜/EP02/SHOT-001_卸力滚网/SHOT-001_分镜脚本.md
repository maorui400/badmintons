# EP02-SHOT-001 卸力滚网

- 版本：`BOARD-v004`
- 时长：`7.0s`
- 绑定：铁蛋 `CHAR-001 v003`；橙超 `CHAR-002 v001`；`ACTION-SMASH-v001`；`ACTION-BLOCK-NET-v001`
- 机位：铁蛋底线后方、腰部高度略低，朝铁蛋背部和橙超方向；不得越过比赛轴线。

## 时间线

1. `0.00–0.90s`：近景是铁蛋背部和准备姿态，远端橙超只做低幅起跳进入杀球末段；鞋底离地约 `10–20 cm`，网与双方场区清楚。
2. `0.90–2.20s`：橙超完成高点击球和随挥，球高速压向铁蛋正手身前；铁蛋分腿垫步、降低重心。
3. `2.20–3.60s`：铁蛋右手短引拍，拍面略开，在身前柔和吸收球速并轻送向远侧网前；无大幅后摆和抡臂。
4. `3.60s` 硬切：贴网带、沿球路的超近特写进入子弹时间。
5. `3.60–6.20s`：羽毛球软木球头领先，以约 `3–6 cm` 的净空从白色网带上方掠过，任何部位均不触网；球头越过网的垂直平面后翻向橙超一侧并下坠。
6. `6.20–7.00s`：硬恢复正常速度，同一只球落在黑网后、橙超侧距网约 `1.98 m` 的横向白色前发球线上；远景可见橙超在落点更后方且来不及触球。

## 关键帧建议

- `KF01` 橙超杀球、铁蛋后场防守准备。
- `KF02` 铁蛋触球前的短引拍与低重心。
- `KF03` 身前卸力触球，拍面略开。
- `KF04` 网带特写，球头贴近但明确高于网带。
- `KF05` 球头已越过垂直面，球与网带之间仍有清晰空气间隙。
- `KF06` 球落远侧网前，橙超迟到。

## 画面硬约束

- 右手持拍与右腕手表同时正确；不得因背视角镜像成左手。
- 先橙超杀球，再铁蛋卸力；球路只跨网两次所对应的一攻一守，不得凭空增加球。
- 子弹时间只改变时间感，不改变球网、羽毛球尺寸和重力关系。
- 橙超不得做夸张腾空；本镜只允许低幅起跳杀球。
- “滚网”是极贴网越过的轨迹描述，不代表撞网或擦网。
- 参与式机位：前半 `BODY-NEAR + P1/P2`；特写 `NET-EDGE + SHUTTLE-PATH + PF/P1`。
# v005 用户反馈修正锁

- 开场橙超杀球时，全镜只能有击球区空中的一只羽毛球；双方地面无球。锚帧：`关键帧/EP02-SHOT-001_start-single-shuttle-lock_v005.png`。
- 落球纵深固定为：铁蛋近场 → 黑色球网 → 网后约 `1.98 m` 绿色地面 → 橙超侧横向白色前发球线上的同一只球 → 橙超身体。
- 黑网网格在球轮廓前形成遮挡，证明球在网后；球不得贴网脚、落入铁蛋场内或穿模。
- 球越过网平面后直至落地，至少两条黑色网格线持续遮住球体局部；不得出现完整无遮挡的羽毛球轮廓，也不得让球覆盖网线。

# EP02-SHOT-005 门外晚风

- 版本：`BOARD-v002`
- 时长：`5.0s`（叙事动作 4.5s + 稳定尾帧 0.5s）
- 绑定：铁蛋 `CHAR-001 v003`；`PROP-BAG-001`；`SCENE-HALL-EXTERIOR-001`
- 机位：主体镜头为铁蛋前侧约 45° 的高位俯视；中段硬切局部毛发超特写，再硬切回同一主体机位。

## 时间线

1. `0.00–1.20s`：铁蛋走出门后停下，门内暖光勾出背包与耳缘。
2. `1.20s` 硬切：脸颊、胡须根和耳缘局部超特写，先建立毛发静止基准。
3. `1.20–3.20s`：同一特写内，只有短毛毛尖和少数胡须受微风产生极小、同向位移；风通常不具象，必要时只在背景使用 `1–2` 条稀疏卷曲流动曲线。
4. `3.20s` 硬切回高位俯视；`3.20–4.50s` 铁蛋轻呼气，视线抬向夜空；`4.50–5.00s` 保持稳定姿态与构图，为下一镜留剪辑余量。

## 画面硬约束

- 冷青月光环境与门内暖黄噪热并存；暖光不得染掉固定银灰毛色。
- 美短是短毛，禁止长发式大幅飘动；风只在局部特写产生低幅、连续、同向的细节变化。
- 主体全景禁止全身抖动线、重影线或密集风线；呼气只允许嘴边一个克制的小弧形气息。
- 不做升格推轨、环绕或升空运镜。

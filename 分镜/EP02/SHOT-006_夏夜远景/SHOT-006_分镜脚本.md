# EP02-SHOT-006 夏夜远景

- 版本：`BOARD-v002`
- 时长：`6.0s`（叙事动作 5.5s + 稳定尾帧 0.5s）
- 场景：`SCENE-HALL-EXTERIOR-001 / MODE-NIGHT-CYAN-RED`
- 转场：从 SHOT-005 末帧按同一空间轴线直接硬切；不是同一镜头继续拉远。

## 时间线

1. `0.00s`：硬切到远得多、朝天空抬起的广角构图。球馆成为画面下方小体量，门洞是唯一明显暖色块。
2. `0.00–3.80s`：冷色夏夜占据主体，月光、薄云、树梢和微风有低幅变化；铁蛋只作为门边小剪影或可辨轮廓。
3. `3.80–5.50s`：球馆远声继续衰减，夏虫和风声接管；画面停留在冷静的夜空。
4. `5.50–6.00s`：固定保持同一远景，作为片尾剪辑余量，不新增事件或运镜。

## 关键帧建议

- `KF01` 硬切后的远景构图：同轴、尺度突变。
- `KF02` 月光、薄云、树梢与暖色门洞的冷暖对照。

## 否决项

- 平滑拉远、无人机升空、变焦、溶解、叠化或匹配移动。
- 夸张星河、快速延时、科幻飞行器或改变球馆建筑结构。
- 门洞暖光扩散成全局橙色，破坏冷色夏夜主体。

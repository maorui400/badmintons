# EP02-SHOT-003 语音消息

- 版本：`BOARD-v002`
- 时长：`8.0s`
- 绑定：铁蛋 `CHAR-001 v003`；`PROP-PHONE-001 v002 / iPhone 16 Pro 黑色钛金属`
- 机位：固定在铁蛋头部侧后方，约肩上视角；同时看清耳部侧影、双手与手机屏幕。

## 时间线

1. `0.00–1.00s`：铁蛋坐在一张长凳的一端；手机、闭合球包、折叠钴蓝毛巾和折叠白蓝备用衣物都直接放在他身旁的同一凳面、同一景深平面。手机屏幕亮起，一次轻提示音。
2. `1.00–2.20s`：铁蛋左手拿起并托住手机，右手食指完成合理解锁动作。
3. `2.20–3.40s`：聊天页显示多条来自对方的白色语音气泡；每条未读气泡右侧有小红点。
4. `3.40–4.20s`：右手食指准确点击第一条，触点与屏幕对应。
5. `4.20–8.00s`：语音依序播放；当前条出现播放进度，播放完成后其红点消失，随后下一条开始。未播放条红点保留。

## 关键帧建议

- `KF01` 手机亮起。
- `KF02` 左手持机、右手解锁。
- `KF03` 多条未读白色语音气泡。
- `KF04` 点击第一条。
- `KF05` 第一条已读、第二条正在播放。

## UI 与动作硬约束

- 手机机身锁定为 iPhone 16 Pro：6.3 英寸比例、灵动岛、黑色钛金属直边、背部三摄与 LiDAR；跨帧不得改变型号和镜头数量。
- 仅使用“常见即时通讯”高层语义：白色圆角语音气泡、波形/时长占位、红色未读点；不得出现微信名称、标志、专属图标或真实联系人信息。
- 屏幕保持同一朝向；手机不翻面、不镜像；左手托持、右指操作全程不换。
- 语音正文为 `CONTENT-PENDING`；未确认前禁止生成可辨识的虚构台词和随机文字。
- 铁蛋的头和手不得遮住关键红点变化。
- 禁止在铁蛋面前生成第二张凳子、桌子或置物台；所有随身物只占用铁蛋所坐长凳的相邻座位。

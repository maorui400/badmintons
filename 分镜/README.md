# 分镜规范

每个镜头必须明确引用剧情段落和人物资产，禁止只写角色名字而不写版本。

建议按“集”建立文件夹，例如：`EP01_初次交锋/`。

## 每镜必填

- 镜头 ID
- 对应剧情段落
- 景别、机位、构图与时长
- 镜头具体空间位置、视线高度、倾角、透视类型和主消失点
- 前景/中景/远景层次及允许形变、禁止形变区域
- 场景和时间
- 出场角色 ID、角色版本、服装版本
- 角色在画面中的位置、朝向、动作、表情与惯用手
- 表情资产 ID、夸张等级 E0–E4，以及进入/峰值/回弹阶段
- 引用的人物锁定图
- 台词、字幕、音效
- 连续性说明
- 一致性审核结果

使用 `镜头清单模板.md` 创建每集镜头清单。

关键动作镜头必须同时遵守 `风格/镜头张力规范.md`。
喜剧反应镜头必须同时遵守 `风格/喜剧表演规范.md`。

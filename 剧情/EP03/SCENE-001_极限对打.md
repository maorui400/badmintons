# EP03 / SCENE-001 极限对打

- 剧情 ID：`STORY-EP03-SCENE-001-v001`
- 风格：`NEON-SHUTTLE-CATS / STYLE-v002`
- 角色：`CHAR-001 v003 铁蛋`、`CHAR-002 v001 橙超`
- 场景：`SCENE-HALL-001 / ENV-v001`
- 目标时长：约 `30s`
- 声音：`BGM: NONE`；只使用现场环境声、脚步、鞋底摩擦、呼吸、衣料、挥拍和击球音效。

## 剧情概述

铁蛋与橙超处于同一回合的高速连续对打中。剧情不急于决出胜负，重点是通过不同焦段、不同视线高度、不同空间位置的固定摄影机进行连续硬切，把普通的一回合对打表现为漫画级攻防拉锯。

## 动作链

1. 橙超从远场把球压向铁蛋后场，铁蛋按正确动力链完成一次右手头顶杀球，球头朝橙超半场下压。
2. 橙超低幅起跳杀球，铁蛋以短引拍防守挡回。
3. 铁蛋把球卸到橙超网前，橙超跨步上网并挑至铁蛋后场。
4. 铁蛋后退到位后完成正手头顶杀球，橙超直线挡回。
5. 双方在中前场进行短促平抽挡，铁蛋戴黑表右手与标准球拍成为近景动作锚点。
6. 橙超突然劈吊斜线，铁蛋全伸展救球；羽毛球贴近镜头飞过，橙超准备下一次进攻时硬切结束。

## 叙事原则

- 六镜属于同一回合；球路、双方场区和上一镜末姿态必须能连接到下一镜首姿态。
- 每镜只使用一台固定摄影机；镜头间直接硬切，不使用平滑变焦、推拉、升降、环绕或溶解。
- 全回合始终只有一只羽毛球。地面不得无故出现备用球，球不得穿过球网实体或角色身体。
- 铁蛋始终是右腕戴黑色闭合手表且由该右手持拍；左腕无表。橙超始终右手持拍。
- 两支成人球拍总长均按约 `675 mm` 锁定。
- 单打双方始终各自在球网一侧：铁蛋近场、橙超远场；任何镜头不得把两人画在同一半场。
- 场地统一绑定 `SCENE-COURT-BWF-001` 标准米制几何及完整单双打画线。

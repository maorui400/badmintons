# EP02 导演脚本

- 版本：`EP02-DIRECTOR-v001`
- 状态：`KEYFRAMES-APPROVED / PROMPTS-READY / API-DISABLED`
- 总生成时长：约 `38s`；成片目标约 `37s`
- 视觉：`NEON-SHUTTLE-CATS / STYLE-v002`
- 主体流程：`SEEDANCE-PIPELINE-v001`

## 导演意图

这一集从“赢下一分”的微小满足，转向一串尚未揭示内容的语音消息，再从燥热球馆切到清凉夏夜。前半段强调专业羽毛球动作和球的触感，后半段降低动作密度，让手机亮光、收拾物品、晚风和冷暖反差接管叙事。

## 时长与节奏

| 镜头 | 时长 | 核心事件 | 剪辑方式 |

## 声音节奏

- SHOT-001：鞋底摩擦、击球爆音、羽毛破风；子弹时间压低环境声。羽毛球不触网，不得添加网带摩擦声。
- SHOT-002：铁蛋轻声说“yes”；球馆声维持，但不得压过对白。
- SHOT-003：手机提示音一次；本轮只生成环境声和 UI 提示，不生成可辨识语音。`VOICE-EP02-001—N` 后期另行配入。
- SHOT-004：毛巾摩擦、拉链和装备入包声、门轴声。
- SHOT-005：球馆声隔门变闷，晚风进入。
- SHOT-006：以冷风、树叶和远处夏虫为主；球馆喧闹只剩暖色门洞方向的低频远声。

## 总否决项

- 铁蛋或橙超身份、服装、毛纹、惯用手、球拍漂移。
- 挡杀放网变成大挥拍、挑高球或力量回抽；滚网球物理错误。
- 手机交互左右手跳变、手指穿屏、界面镜像、随机可读文字或直接复制微信品牌资产。
- 收包时出现瞬移、物品穿模或同一物件同时在手中和包内。
- SHOT-005 到 SHOT-006 被生成成连续升空、平滑拉远或溶解过渡。

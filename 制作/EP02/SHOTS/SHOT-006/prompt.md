# EP02-SHOT-006 Seedance Prompt v002

`NEON-SHUTTLE-CATS, STYLE-v002 / MODE-NIGHT-CYAN-RED`。本镜从 SHOT-005 末帧同一空间轴线纯硬切进入，不呈现中间移动。切后是远得多、朝天空抬起的固定广角：冷青夏夜和月光薄云占据主体，树梢随微风低幅摆动；球馆缩在画面下方，门洞是唯一明显暖黄区域，铁蛋只作为门边小剪影。球馆喧闹变成远处闷声，冷风和夏虫声接管。

镜头切后保持固定。5.50–6.00 秒保持同一固定远景作为剪辑余量，不新增运镜或事件。禁止平滑拉远、升空、变焦、无人机运动、溶解或叠化；禁止夸张星河、快速延时、科幻飞行物、改变球馆结构、暖色铺满夜空、随机文字、写实摄影和 3D 塑料感。

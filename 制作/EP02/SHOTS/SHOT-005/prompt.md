# EP02-SHOT-005 Seedance Prompt v002

`NEON-SHUTTLE-CATS, STYLE-v002`。绑定铁蛋 `CHAR-001 v003 / COST-B / PROP-BAG-001`。0–1.20 秒为铁蛋前侧约 45° 的高位俯视，铁蛋走出门后停下，门内暖黄光勾出背包和耳缘，外部是冷青月光，主体周围没有风线或抖动线。1.20 秒硬切到脸颊、胡须根与耳缘的局部超特写，先建立短毛静止基准；随后只让毛尖和少数胡须产生极小、同向位移，通常不画风，必要时只在背景保留 1–2 条稀疏卷曲动漫流线。3.20 秒硬切回原高位俯视，铁蛋轻呼气并抬眼看向夜空，只允许嘴边一个克制的小弧形气息。4.50–5.00 秒保持稳定姿态和构图，作为剪辑余量，不新增动作。

保持银灰美短短毛结构。禁止全身颤动、全身重影线、密集风线、长发式飘动、炸毛风暴、方向冲突的局部风、用平滑推拉代替两次硬切、升格推轨、环绕、升空运镜、暖光污染全身毛色、随机文字、写实摄影和 3D 塑料感。

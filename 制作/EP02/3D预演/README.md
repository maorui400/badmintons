# EP02 Blender 3D 导演预演

- 工程：`EP02_3D导演预演_v001.blend`
- 生成脚本：`build_ep02_previs.py`
- 预览：`预览/EP02-SHOT-001_camera-preview_v001.png` 至 `EP02-SHOT-006_camera-preview_v001.png`
- Blender：4.5 LTS

## 用途

这是 EP02 的空间、站位、透视和镜头轴线预演，不是正式角色渲染。工程将六个镜头拆成六个相互隔离的 3D 导演台，每个导演台都有独立相机和灯光，可在 Blender 中直接移动角色代理、相机、球网、门、凳子与外景物件。

## 已固定的连续性

- 标准羽毛球场尺寸 13.4m × 6.1m，球网顶高 1.524m。
- 铁蛋近场、黑色球网、远场网前落点、橙超的景深顺序。
- SHOT-001 只放置一只羽毛球，并位于橙超半场网前发球线附近。
- 铁蛋黑色手表始终只在解剖学右腕；球拍固定于右手。
- 成人球拍代理总长固定为 0.675m。
- SHOT-003 手机、球包、毛巾和衣物与铁蛋位于同一张凳子。
- SHOT-004 门向球馆内部开启，铁蛋的移动方向为从馆内到室外。
- SHOT-005/006 使用同类轴线，形成近景到远景的硬切关系。

## 注意

角色使用简化猫科代理模型，只承担构图和动作关系验证。正式人物五官、毛纹、服装细节仍以锁定人物资产为准。

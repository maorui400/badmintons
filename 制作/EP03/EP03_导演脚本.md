# EP03 导演脚本

- 脚本 ID：`EP03-DIRECTOR-v001`
- 剧情：`STORY-EP03-SCENE-001-v001`
- 总长：约 `30s`
- 结构：六个约 `5s` 生成单元，后期纯硬切
- 声音：`BGM: NONE`

## SHOT-001 / 后场建立

- 时长：`5.0s`
- 焦段感：`35mm`
- 机位：铁蛋近侧底线后方约 1.6m 高，略偏左，朝向橙超半场。
- 透视：`P1 强单点`；铁蛋背部与右手球拍为近景，黑网为中景，橙超为远景。
- 动作：橙超将球压向铁蛋右后场；铁蛋交叉调整、侧身引拍，按 `ACTION-SMASH-v001 / P4—P5` 在肩前上方触球后完成自然跨体随挥，将球下压至橙超场地。
- 镜头：完全固定；击球时仅允许极轻微冲击震动。
- 剪辑出口：羽毛球球头朝橙超半场、羽毛裙拖后，沿下压线路越网时硬切。

## SHOT-002 / 场地贴地压迫

- 时长：`5.0s`
- 焦段感：`20mm`
- 机位：左侧双打边线外，距地约 0.18m，前景压入铁蛋近侧鞋和边线。
- 透视：`P2 倾斜两点`；边线强烈收束，球网斜贯画面。
- 动作：橙超移动到位，按 `ACTION-SMASH-v001` 做低幅起跳杀球；铁蛋降低重心，以短引拍正手防守挡回。
- 允许形变：近侧鞋、球拍框和羽毛球的速度性透视放大。
- 禁止形变：脸、耳朵、手表、球拍真实长度、球网结构。
- 剪辑出口：铁蛋挡球离拍、球向橙超网前飞行时硬切。

## SHOT-003 / 长焦网前压缩

- 时长：`5.0s`
- 焦段感：`85mm`
- 机位：右侧网柱外约 1.55m 高，近似沿球网方向拍摄。
- 透视：长焦压缩；前景网柱、铁蛋挡放点、橙超跨步形成紧密纵深。
- 动作：铁蛋按 `ACTION-BLOCK-NET-v001` 把球卸到橙超网前；橙超右脚跨步、拍头先到球下方，将球挑向铁蛋后场。
- 视觉重点：球越过网的平面关系清楚，黑网可局部遮挡球但不能吞掉触球点。
- 剪辑出口：橙超挑球离拍并快速上升时硬切。

## SHOT-004 / 战术俯视追赶

- 时长：`5.0s`
- 焦段感：`28mm`
- 机位：铁蛋左后方场角上空约 7m，45° 三点俯视。
- 透视：`P3`；完整场线作为运动路径图。
- 动作：铁蛋以并步加交叉步后退到右后场，转体完成正手头顶杀球；橙超保持低重心，在远场把球直线挡回。
- 视觉重点：双方脚步路径、球路和场区位置一眼可读；禁止人物在场地上瞬移。
- 剪辑出口：橙超挡回的球沿直线冲向铁蛋中场时硬切。

## SHOT-005 / 戴表右腕与平抽挡

- 时长：`5.0s`
- 焦段感：`50mm`
- 机位：铁蛋右肩后侧 `BODY-NEAR`，镜头贴近持拍前臂但不裁掉手表与握拍点。
- 透视：前景为黑表右腕、手柄与拍杆；橙超位于浅景深远层。
- 动作：铁蛋迎前做一次短促正手平抽，橙超回抽，铁蛋再以紧凑反手/身前挡抽把球送向斜线。
- 硬约束：黑表只在右腕，右腕始终控制球拍；球拍总长不因近景而物理伸缩。
- 剪辑出口：第二次击球后羽毛球横穿画面右侧时硬切。

## SHOT-006 / 网柱危险区终局悬念

- 时长：`5.0s`
- 焦段感：`18mm`
- 机位：贴近右侧网柱、距地约 0.35m，受控约 7° 荷兰倾角。
- 透视：`PF 受控超广角`；网柱和网格为极近前景，脸部位于中央安全区。
- 动作：橙超抢高点劈吊斜线；铁蛋从中场向前全伸展跨步救起，羽毛球从镜头旁极近处掠过并重新升向橙超。橙超抬拍准备下一次进攻，在胜负未决处结束。
- 特效：击球瞬间允许 2–3 帧硬边速度线；禁止能量球、光束和球体变形。
- 结尾：不拉远、不淡出；橙超准备动作与空中唯一羽毛球同时保留，直接硬切黑场。

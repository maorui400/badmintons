## v003 相对 v002 的升级

1. **语义拆分**：12 个通用姿态 → 23 个语义姿态。
   - 高远球击球 `contact_clear` 与杀球击球 `contact_smash` 不再共用同一组角度。
   - 杀球随挥拆出 `follow_clear` / `follow_smash` / `land_smash`，回位、防守、吊球收势各自独立。
2. **通道扩充**：驱动通道从 6 个扩到 18 个，启用 `hand.R` / `hand.L` 拍面、`head` 视线、
   `spine` 分段躯干、`foot.R` / `foot.L` 踝关节、`elbow_pole.*` 肘朝向。
3. **修复无效旋转**：实测 IK 约束 `use_rotation=False`，v002 写在 `hand_ik.*` 后三位的手腕角度
   全部不生效；v003 改由形变骨 `hand.R` 的旋转控制拍面。
4. **修复渲染相机切换**：Timeline Marker 的 `marker.camera` 会在渲染时覆盖 `scene.camera`，
   导致六机位串位。已解除 marker 的 camera 绑定，改为渲染循环内显式按 `shot_id` 切相机。

## 硬规则自检

| 规则 | 结果 | 说明 |
|---|---|---|
| 铁蛋黑表 = 右腕 = 持拍腕 | 通过 | 各镜头目测黑表均只在右手腕，与球拍同腕；左腕无表 |
| 球拍约 675mm / 身高 40% | 通过 | 代理球拍总长固定 0.675m，跨帧未见伸缩或比例漂移 |
| 双方隔网 | 通过 | 铁蛋 `Y<0`、橙超 `Y>0`，无同侧站位 |
| 全回合唯一羽毛球 | 通过 | 每镜头仅见一个羽毛球控制器 |
| BGM: NONE | 通过 | 工程未添加任何音源 |
| 六机位纯硬切 | 通过 | 工程仅 6 个相机，按 `shot_frames` 逐帧硬切 |

## 已知问题 / 待蛋导确认

1. **击球点与球不重合**：预演是阻塞姿态示意。角色臂长约 0.696m，站立时手最高约 2.0m，
   而剧本球路高度达 2.45m，无法精确接触。二维主锚帧阶段由画师精修击球点。
2. **橙超 f1 动作沿用 `drive_forehand`**：与 v002 一致。视觉上橙超在开局即处于"已击球"状态，
   如需改为 `stance_ready` 可一键调整。
3. **SHOT-003 KF03 橙超被网遮挡**：85mm 长焦机位本身带网前景遮挡，动作意图仍可辨认。
4. **姿态仍待逐帧审美确认**：v003 是初稿，拍面角度、重心高度、步法幅度都可继续迭代。

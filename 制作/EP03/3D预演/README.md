## 工程结构

- `EP03_MASTER_COURT`：标准球场、黑网、铁蛋/橙超代理、唯一羽毛球、六台真实摄影机。
- `EP03_CAMERA_MAP_GUIDES`：可渲染的机位点、视线箭头、焦段标签与图例。
- `CAM_EP03_MAP_TOP`：顶视空间图。
- `CAM_EP03_MAP_PERSPECTIVE`：透视空间图。
- `CAM_EP03_SHOT-001—006`：六个正式预演机位。

时间轴按 `24fps` 设置为720帧，每120帧建立一个带摄影机名称的 Marker，分别对应六个约5秒单元。为避免 Marker 自动覆盖手动选择的活动摄影机，本版不强制绑定相机；可在 Outliner 中选择 `CAM_EP03_SHOT-001—006` 后按 `Ctrl+小键盘0` 切换。

## 骨骼 IK 动作版

- 当前工程：`EP03_骨骼IK动作预演_v002.blend`
- 构建脚本：`build_ep03_rigged_previs.py`
- 操作说明：`骨骼IK动作预演说明.md`
- 当前姿态抽帧：`动作关键帧_v002/`，六镜各 4 张，共 24 张
- 状态：`EP03-RIG-PREVIS-v002 / USER-REVIEW-PENDING`

v002 将球场替换为 `SCENE-COURT-BWF-001` 的标准米制几何：全场 `13.40 × 6.10 m`、单打宽 `5.18 m`、线宽 `40 mm`，完整保留单双打边线、前发球线、双打后发球线、底线和中线。双方代理分别锁定在 `Y<0` 与 `Y>0`，黑色球网位于 `Y=0`；该空间关系不因焦段或机位改变。

铁蛋和橙超均有全身骨架、双手/双脚 IK、肘膝 Pole 控制器。时间轴已经编入六镜连续动作链；角色动作使用 Constant 插值形成漫画式姿态硬切，羽毛球轨迹使用 Bezier 插值保持飞行连续。当前角色仍是用于空间和动作审核的简化代理，不替代正式二维角色资产。

铁蛋的黑色闭合手表与成人标准球拍都锁定在解剖学右手；左腕无表。两名角色球拍均按约 `675 mm` 真实成人规格制作。旧 `v001` 工程与抽帧仅作历史对照，不得替代 v002。

声音默认规则：`BGM: NONE`，只允许现场音效、环境声和必要对白。

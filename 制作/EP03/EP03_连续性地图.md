# EP03 连续性地图

- 地图 ID：`EP03-CONTINUITY-v001`
- 范围：`SHOT-001—SHOT-006`

## 空间基准

- 坐标约定：铁蛋近场为 `Y<0`，橙超远场为 `Y>0`；黑色球网位于 `Y=0`。
- 铁蛋始终属于近场，橙超始终属于远场；只有正常换边剧情才能改变，EP03 不换边。
- 主体深度基准：近侧摄影机/前景物 → 铁蛋 → 黑网 → 橙超 → 远侧底线。
- 场地几何绑定：`SCENE-COURT-BWF-001 / 13.40 × 6.10 m / 1 unit = 1 m`；单双打场线必须完整，禁止为构图缩放或改线。
- 单打硬规则：双方脚底落点不允许同时位于 `Y<0` 或同时位于 `Y>0`；长焦压缩只改变投影，不改变分场关系。

## 动作与球路接续

| 切点 | 上一镜末状态 | 下一镜首状态 |
|---|---|---|
| 001→002 | 铁蛋杀球下压，橙超在远场完成挡起并回出下一拍高球 | 橙超追到下一拍高球下方，准备低幅起跳杀球 |
| 002→003 | 铁蛋把杀球挡向橙超网前 | 羽毛球继续下坠，橙超启动跨步 |
| 003→004 | 橙超从网前挑向铁蛋后场 | 铁蛋转身后退追球 |
| 004→005 | 橙超直线挡回铁蛋中场 | 铁蛋右腕在身前迎球平抽 |
| 005→006 | 球被斜线送回橙超前半场 | 橙超抢高点劈吊，铁蛋启动救球 |

## 硬性否决

- 任意镜头出现两只及以上羽毛球，或地面无故出现球。
- 球未跨过网的垂直平面却落到另一方场地，或球/人物/球拍穿过黑网实体。
- 铁蛋缺少右腕黑表、手表出现在左腕、出现双表，或球拍离开戴表右手。
- 橙超换成左手持拍。
- 球拍偏离约 `675 mm` 成人规格，跨镜缩短或拉长。
- 羽毛球没有以球头/软木端朝飞行方向，或球拍、羽毛球、角色穿过网柱/网面。
- 单打双方出现在球网同一侧，或场线不符合 `SCENE-COURT-BWF-001`。
- 用平滑拉远、平滑变焦、连续环绕或溶解代替六机位硬切。
- 未经明确批准出现背景音乐。

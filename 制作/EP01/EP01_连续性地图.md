# EP01 连续性地图

## 全片不变量

- 风格：`NEON-SHUTTLE-CATS / STYLE-v002`。
- 主角：`CHAR-001 / 铁蛋 / v003`。
- 办公镜头只使用已锁定 `COST-OFFICE-A / SHOT-001-LOCKED-v001`。
- 球馆段固定 `COST-B / TOP-001 v001 / BOTTOM-001 v001 / SHOE-001 v001 / RACKET-001 v001`。
- 铁蛋始终右手持拍，哑光黑表固定在右腕且表带环绕整周。

## SHOT-001 → SHOT-002

- `SHOT-001` 尾帧：办公超远景，铁蛋缩在重复工位中；无声。
- `SHOT-002` 首帧：球馆门外背后三分之四身；左手将要推门，右手持拍。
- 转场：直接硬切，不使用末帧延续、不做办公室到球馆的形变转场。
- 叙事关系：从“被工作系统吞没”切到“主动推开球馆入口”。
- 服装变化属于时间/地点省略，允许由办公装直接切为 `COST-B`。

## SHOT-002 → SHOT-003

- 共享环境：`SCENE-HALL-001`；场灯冷暖、地面颜色、门和主场位置保持一致。
- `SHOT-002` 尾部铁蛋在入口前景；`SHOT-003` 直接切到同馆场边热身区。
- 不要求尾帧驱动首帧；用共享环境母版和角色锁定图维持一致性。
- 球馆击球、人声与鞋声跨镜连续，不做声场清空。

## SHOT-003 → SHOT-004

- `SHOT-003` 末尾铁蛋完成右手头顶影子挥拍并回到中立。
- `SHOT-004` 开头铁蛋仍在场边；画外呼喊来自画面右侧。
- 铁蛋先动耳、再动眼、最后转头，保持其喜剧表演顺序。
- `SHOT-004` 尾帧：铁蛋位于主场近侧中场，面向远侧，完成接发准备姿态。

## SHOT-004 → SHOT-005

- 使用动作轴：铁蛋在近侧半场，对手在远侧半场，网横贯画面中部。
- `SHOT-005` 首段可引用 `SHOT-004` 末帧保持服装、位置和方向；因此批次设置 `continuity_from: SHOT-004`。
- 球路固定为：近侧下方挑至远侧上方，再由远侧上方杀回近侧下方。
- 铁蛋挑球与对手跳杀不可镜像；越网方向不得反转。
- `SHOT-005` 尾帧是 `EXP-003 E4` 错愕特写，可作为下一喜剧镜头的反应入口。

## SHOT-005 → SHOT-006

- `SHOT-006` 尚未收到剧情，连续性未定义。
- 在用户明确第六镜前，不得决定铁蛋是否回弹、说话、继续比赛或切换场景。

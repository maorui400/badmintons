## 新设备恢复步骤

### 1. 配置本机凭证

在火山引擎控制台创建或取得当前账号的方舟 API Key 与 TOS AK/SK，仅保存到 Windows
用户环境变量：

- `ARK_API_KEY`
- `TOS_ACCESS_KEY`
- `TOS_SECRET_KEY`

不得把值粘贴到聊天或项目文件。可运行：

```powershell
powershell -ExecutionPolicy Bypass -File 工具\seedance\configure_tos_credentials.ps1
```

方舟 Key 使用同样原则单独写入 `ARK_API_KEY`。

### 2. 安装依赖

```powershell
python -m pip install tos==2.9.2
```

### 3. 刷新 TOS 签名链接

原链接过期、新设备没有 `runtime/`，或提交前剩余有效期不足时，运行：

```powershell
$env:TOS_ACCESS_KEY = [Environment]::GetEnvironmentVariable('TOS_ACCESS_KEY', 'User')
$env:TOS_SECRET_KEY = [Environment]::GetEnvironmentVariable('TOS_SECRET_KEY', 'User')
python 工具\seedance\tos_upload_refs.py
```

成功标准：输出 `uploaded: 4`、`acl: private`、`signed_url_ttl_hours: 72`。

### 4. 离线复核

```powershell
工具\seedance\seedance.cmd validate 制作\EP01\EP01_批次清单.json
工具\seedance\seedance.cmd compile 制作\EP01\EP01_批次清单.json
```

成功标准：错误和警告均为 `0`，`network_ready_shots: 1`，`unresolved_shots: []`。

### 5. 当次付费确认后提交

先把 `ARK_API_KEY` 加载到真实用户进程；只有当前对话收到明确确认后才能运行：

```powershell
$env:ARK_API_KEY = [Environment]::GetEnvironmentVariable('ARK_API_KEY', 'User')
工具\seedance\seedance.cmd submit 制作\EP01\EP01_批次清单.json `
  --approve-api-call API_CALL_CONFIRMED_FOR_THIS_RUN
```

提交成功后立刻把任务 ID 和提交时间写回本文档，再进行状态查询、下载和质检。

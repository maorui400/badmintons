# 铁蛋｜表情资产

- 角色 ID：`CHAR-001`
- 角色版本：`v002`
- 风格版本：`STYLE-v002`
- 表演规范：`COMEDY-v001`
- 状态：`SPEC-READY / IMAGE-PENDING`

铁蛋的表演核心是“先一本正经地停顿，再突然失控”。所有表情必须保留：

- 额头三道深色纵纹组成的 M 形。
- 双颊三组深灰弧形条纹。
- 银灰/白色脸部分区与粉色鼻头。
- 中等偏大三角耳和低饱和灰绿色虹膜（虹膜可见时）。

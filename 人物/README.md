# 人物资产规范

## 必备资产

每个角色建立一个独立文件夹，并至少包含：

1. `角色设定.md`：角色 ID、外形锚点、身体比例、惯用手、服装和装备。
2. `三视图/`：正面、侧面、背面；必须是同一服装版本、同一比例、同一画风。
3. `补充视角/`：四分之三正面、四分之三背面、俯视、仰视等必要参考。
4. `表情/`：兴奋、生气、错愕、愤怒、开怀大笑、哭泣六种必备表情资产。
5. `表情动作/`：羽毛球技术动作、手部持拍细节及表情与动作的组合参考。
6. `球衣/`、`鞋子/`、`球拍/`：可独立切换的品牌、型号和外观资产。

本项目中的人物统一为“猫科福瑞化角色”。除通用人物设定外，还必须锁定猫科物种、
耳形、耳位、口鼻部、眼型、毛色分区、毛纹、尾巴和脚掌结构。具体规则见
`风格/视觉圣经.md`。

复制 `_角色模板/` 创建新角色，文件夹命名为：

`角色ID_角色名`

示例：`CHAR-001_林跃`

## 一致性硬规则

- 角色 ID 永久唯一，不因剧情阶段改变。
- 三视图审核通过后标记为 `LOCKED`；变更必须升级角色版本。
- 脸型、五官间距、发型轮廓、发色、肤色、体型与身高比例属于不可漂移项。
- 猫科物种、耳形、耳位、口鼻长度、毛色分区、毛纹、尾巴形态属于不可漂移项。
- 明确记录左/右手持拍，所有镜头必须一致；剧情要求改变时需在镜头中说明。
- 服装、鞋、护具、球拍分别设置版本号，禁止在连续场景中无理由变化。
- 球拍在角色档案中使用数组记录；每个分镜通过球拍资产 ID 指定当前使用型号。
- 指定品牌和型号时，生成前必须读取对应官方或电商商品链接；无法唯一确定 SKU、
  配色或涂装时，必须先向用户索取链接，不得凭印象生成。
- 同一场景优先复用同一组角色参考图、提示词锚点、随机种子与生成参数。
- 每个角色建档时同步建立六种基础表情；E3–E4 表情必须记录进入、峰值和回弹阶段。
- 新生成图片不得反向取代锁定三视图；只有人工审核通过后才能升级基准资产。

## 推荐文件命名

`角色ID_资产类型_视角或动作_角色版本_服装版本_序号.扩展名`

示例：

- `CHAR-001_turnaround_front_v001_COST-A_001.png`
- `CHAR-001_turnaround_side_v001_COST-A_001.png`
- `CHAR-001_turnaround_back_v001_COST-A_001.png`
- `CHAR-001_action_smash_v001_COST-A_001.png`

## 生成前检查

- 角色 ID、角色版本、服装版本是否明确。
- 引用图是否来自该角色的锁定资产。
- 发型、脸型、体型、惯用手、球拍与服装是否写进提示词。
- 多角色同框时，是否分别绑定各自参考图与位置。

## 生成后检查

- 正面、侧面和背面能否确认是同一个人。
- 连续镜头中五官、发型、身材比例是否漂移。
- 左右手、服装编号、鞋、护具和球拍是否连续。
- 近景与远景的角色特征是否仍可辨认。
- 不合格资产移出正式素材区，不得进入视频合成。

# 参考来源与转译说明

本项目研究《赛博朋克：边缘行者》的目的，是理解其高层视觉语言并建立原创体系，
不是复制受保护的角色、标识、场景、服装或具体镜头。正式生成提示词优先使用
`视觉圣经.md` 中的描述，而不是直接使用作品名。

## 官方来源

1. Cyberpunk: Edgerunners 官方页面  
   https://www.cyberpunk.net/en/edgerunners  
   用途：确认创作团队、角色呈现方式与科技都市背景。

2. Netflix 官方制作公告  
   https://about.netflix.com/en/news/netflix-cd-projekt-red-and-studio-trigger-come-together-for-global-anime-cyberpunk-edgerunners  
   用途：官方将动画工作室的表达概括为鲜明、充满活力的风格，并列出主要创作人员。

3. Netflix 官方作品页面  
   https://www.netflix.com/title/81054853  
   用途：确认作品的快节奏、爆发性、粗粝、反乌托邦和动作向基调。

4. Studio TRIGGER 官方作品页  
   https://www.st-trigger.co.jp/works/cyberpunk-edgerunners/

   用途：研究角色设计如何通过稳定的服装、颜色、轮廓和局部细节维持识别度。

6. David、Lucy、Rebecca 官方角色细节指南  
   https://cdn-s-cyberpunk.cdprojektred.com/cosplay-guides/DAVID_MARTINEZ_COSPLAY_GUIDE_EN.pdf

   https://cdn-s-cyberpunk.cdprojektred.com/cosplay-guides/REBECCA_COSPLAY_GUIDE_EN.pdf  
   用途：只研究“角色资产应记录到什么粒度”，不复制其中任何现有设计。

## 已转译为本项目的原创方向

- 科技改造都市 → 智能球馆、训练数据、电子边线和可穿戴运动科技。
- 高能量动画 → 真实羽毛球动作上的关键帧夸张、速度透视和短促残影。
- 高饱和对撞 → 本项目自建的冷青、红橙、酸黄、洋红信号色体系。
- 强角色轮廓 → 猫耳、发型、体型、尾巴、球拍组成独特剪影。
- 身体与科技冲突 → 运动员的竞技压力、身体极限与装备依赖。

## 禁止转入项目的内容

- 原作人物或其猫化版本。
- 原作服装、植入物、企业标志、城市名称和专属物件。
- 原作海报、截图或镜头的近似重构。
- 用原作名称替代本项目自身的视觉描述。

## 动作构图研究：itokazu taiga / itokazuuu

公开页面与第三方整理显示，该作者尤其受到关注的是强烈广角/鱼眼感、非常规视点和
复杂透视下的战斗瞬间。我们只研究这些高层构图方法，并将其转译为
`镜头张力规范.md` 中的原创镜头语法。

来源：

- 作者 Bluesky 公开资料：  
  https://bsky.app/profile/itokazuuu.bsky.social
- 作者 X：  
  https://x.com/itokazuuu
- 作者 Instagram：  
  https://www.instagram.com/itokazuuuu/
- 关于其非常规视角与复杂透视的第三方作品介绍：  
  https://cheezburger.com/40940549/revisit-the-most-legendary-anime-battles-from-a-new-perspective-with-unique-pov-fan-art

作者公开资料明确标注禁止 AI 学习、无授权转载和商业使用。因此本项目执行以下边界：

- 不下载、收集或复制作者图片进入仓库。
- 不把作者图片上传为图像生成参考、训练材料或风格适配素材。
- 不在生成提示词中使用作者姓名或账号名。
- 不复刻任何具体作品的角色、动作组合、镜头位置或构图。
- 只使用通用的透视、镜头、景深、遮挡和运动叙事知识创作全新画面。

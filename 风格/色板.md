# 色板与用色规则

本色板是原创项目色板，不是对任何单一作品画面的逐像素提取。

## 基础城市色

| 名称 | HEX | 用途 |
|---|---:|---|
| 深夜墨蓝 | `#090D1A` | 背景暗部、外轮廓 |
| 沥青蓝 | `#17243B` | 建筑、球馆暗面 |
| 钢铁灰蓝 | `#52647A` | 中间调、设备 |
| 冷雾白 | `#E8F1F2` | 字幕、眼部高光、球衣亮面 |

## 高频信号色

| 名称 | HEX | 用途 |
|---|---:|---|
| 电光青 | `#28D7F5` | 数据、冷边光、速度提示 |
| 热能洋红 | `#FF3D91` | 情绪压力、对手侧强调 |
| 酸性黄 | `#F1E84B` | 警告、记分、关键视觉锚点 |
| 冲击红橙 | `#FF4B3E` | 危险、爆发、比赛高潮 |
| 脉冲青绿 | `#69F5A2` | 训练数据、恢复、技术反馈 |
| 暮紫 | `#7C4DFF` | 夜景过渡，禁止大面积滥用 |

## 用色公式

- 常规夜景：`深夜墨蓝 55% + 沥青蓝 25% + 角色固有色 15% + 信号色 5%`
- 比赛高潮：`暗色 45% + 角色固有色 25% + 两种对撞信号色 30%`
- 情绪近景：`一个背景纯色块 + 角色固有色 + 一个眼部/边缘强调色`
- 设定三视图：使用中性冷雾灰背景，禁止霓虹光污染角色固有色。

## 角色色彩约束

- 每个角色固定 1 个主毛色、1 个次毛色和 1 个个人强调色。
- 同队服装共享主色，但角色个人强调色用于号码边缘、手胶、耳饰或小面积灯条。
- 对手之间需要在明度或冷暖上拉开，不能只改变色相。
- 毛色在任何场景都以角色设定中的 HEX 为基准；环境光只能影响受光面，不能改掉身份色。

## 场景色彩模式

- `MODE-NIGHT-CYAN-RED`：冷青城市环境 + 红橙比赛冲突。
- `MODE-COURT-YELLOW-BLUE`：酸黄记分与警告 + 蓝色球馆暗面。
- `MODE-TRAIN-GREEN`：青绿训练数据 + 低饱和背景。
- `MODE-EMOTION-MAGENTA`：洋红情绪压迫 + 深墨蓝暗部。
- `MODE-DAY-HARSH`：高亮冷白日光 + 硬阴影 + 少量信号色。
- `MODE-COMEDY-YELLOW`：酸黄纯色或放射底，用于兴奋、得意和开怀大笑。
- `MODE-COMEDY-WHITE`：冷雾白抽空背景，用于错愕、冷场和停顿笑点。
- `MODE-COMEDY-RED`：红橙冲击底 + 粗黑线，用于 E4 愤怒爆发。
- `MODE-COMEDY-CYAN`：电光青/钢铁蓝流动底，用于哭泣、慌乱和灵魂出窍感。

同一连续场景只选择一个主模式；切换必须由剧情、地点或时间变化驱动。
喜剧峰值允许短暂切换为 `MODE-COMEDY-*`，回弹帧必须恢复原场景模式。

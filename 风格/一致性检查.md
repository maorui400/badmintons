# 风格与角色一致性检查

每张正式图片和每个视频镜头按 100 分审核。低于 90 分不得进入正式素材区；
任一“否决项”失败时，无论总分多少都必须重做。

## 否决项

- [ ] 角色 ID、角色版本、服装版本与分镜一致；上衣、下衣资产 ID 均已填写。
- [ ] 猫科原型、耳形、毛色分区、固定毛纹和尾巴完全匹配锁定三视图。
- [ ] 惯用手、握拍、球拍和羽毛球动作正确。
- [ ] 铁蛋的黑色闭合手表始终只在解剖学右腕；凡属持拍镜头，球拍必须由这只戴表右手握持。前视、背视、侧视或镜像构图均以“黑表腕＝右腕＝持拍腕”为判别锚点，空着的左腕不得出现手表。
- [ ] 铁蛋正背视屏幕映射正确：标准正视中，持拍右手/黑表位于画面左侧；标准背视中，持拍右手/黑表位于画面右侧。背视挥手帧必须是“画面左侧无表左手挥手，画面右侧戴表右手持拍”。
- [ ] 球拍总长、拍框、拍杆和手柄比例与绑定型号一致；成人标准拍默认按约 `675 mm`，
  同一角色跨镜不得缩短、伸长或因景别变化改变相对身体比例。
- [ ] 所有成年角色均按约 `675 mm / 各自站立身高40%` 复核拍长；任一角色出现儿童短拍、异常长拍、拍杆折弯或跨帧尺度跳变，直接触发否决。
- [ ] 铁蛋全镜头必须恰好一块黑色闭合手表且只在解剖学右腕；右腕缺表、左腕有表或双表，无论是否持拍均直接触发否决。
- [ ] 技术动作已绑定当前 `ACTION-*` 版本；阶段顺序、动力链、触球点、随挥和落地均通过。
- [ ] 单打回合中双方始终分别位于球网两侧、各自半场内；除明确换边剧情外，严禁两人同时出现在同一侧场地。发现即否决并立即修正。
- [ ] 场地绑定 `SCENE-COURT-BWF-001`：`13.40 × 6.10 m` 双打外框、`5.18 m` 单打宽度、`40 mm` 场线，以及短发球线、双打后发球线、中央发球线完整且位置正确。
- [ ] 羽毛球飞行时始终由球头/软木端领航、羽毛裙朝后；球头必须朝实际飞行与落点方向，不得横飞或倒飞。
- [ ] 人物、球拍、球场与球网保持统一米制比例；球拍或肢体不得穿过网柱、网面、地板或另一角色实体。
- [ ] 没有复制参考作品的现有角色、服装、标志或具体镜头。
- [ ] 没有多余肢体、手指错误、尾巴穿模或角色融合。
- [ ] E3–E4 表情保留至少三个身份锚点，并存在进入帧与回弹帧。

## 评分表

| 项目 | 分值 | 检查内容 |
|---|---:|---|

## 喜剧表演附加检查

- [ ] 表情资产 ID、表情名称和夸张等级 E0–E4 已填写。
- [ ] 生气为 E2 左右的不爽/憋气，愤怒为 E4 爆发，两者没有混用。
- [ ] 固定额纹、脸纹、毛色分区、耳尾数量至少保留三个可见锚点。
- [ ] 夸张没有导致角色年龄、物种、惯用手或装备改变。
- [ ] E3–E4 有进入帧、峰值帧和回弹帧，峰值没有变成永久模型。
- [ ] 笑点结束后场景色彩模式和角色比例恢复。

## 镜头张力附加检查

- [ ] 机位有明确空间位置，不是抽象的“酷炫角度”。
- [ ] 透视类型、地平线、主消失点和空间线索一致。
- [ ] 至少存在两个清晰的景深层次；关键动作镜头推荐三个层次。
- [ ] 极近前景强化动作方向，没有遮住身份锚点或关键触球信息。
- [ ] 允许形变与禁止形变区域已写入分镜。
- [ ] 独特视角仍能看清球、拍、网、触球点和角色重心。
- [ ] 与上一镜的轴线、屏幕方向和球路衔接成立。

## 杀球动作附加检查

- [ ] 引拍阶段持拍肘屈曲、拍头在头后，没有提前锁直手臂。
- [ ] 下肢蹬伸与髋肩旋转可读，发力不是只来自手腕或小臂。
- [ ] 击球点位于持拍肩前上方，肘先于前臂和拍头通过，拍面指向目标线路。
- [ ] 触球后存在自然跨体随挥、下降、屈髋屈膝落地与回位。
- [ ] 换机位后，关节关系、球网轴线、双方场区与球路仍符合 `ACTION-SMASH-v001`。

## 球拍尺度附加检查

- [ ] 已读取球拍资产的毫米总长；无明确规格时不得凭单帧构图任意缩放。
- [ ] `RACKET-001` 固定总长约 `675 mm`，约为七头身成年铁蛋身高的四成；透视只允许改变
  画面投影，不得改变球拍在三维空间中的真实长度。
- [ ] 全拍可见时，拍框、拍杆和手柄比例与商品参考一致；局部出画时不得把截断部分误判为短拍。
- [ ] 同一镜头前后帧以及相邻镜头中，握点到拍头的长度连续，不得伸缩、折叠或瞬间变形。
- [ ] 不同成年角色同场时分别按同一约 `675 mm` 物理尺度比较；角色身高差只改变球拍占身高的轻微视觉比例，不得把任一人的拍画成短拍或长拍。
- [ ] 羽毛球拍框必须是细长椭圆羽毛球拍框，禁止膨胀成网球拍、壁球拍或不完整圆环；握把、拍杆、T 形连接区和拍框必须连续且不与手掌融合。

## 球场与双方分区附加检查

- [ ] Blender 场地来源是 `场景/SCENE-COURT-BWF-001/SCENE-COURT-BWF-001_v001.blend`，且 `1 unit = 1 m`。
- [ ] 铁蛋位于 `Y<0` 近场、橙超位于 `Y>0` 远场、球网位于 `Y=0`；EP03 全集不换边。
- [ ] 即使长焦压缩、网格虚化或极低机位造成视觉重叠，人物脚底落点仍必须分别处于网面两侧。
- [ ] 俯视镜头能辨认双打外边线、单打边线、两条短发球线、两条双打后发球线、两段中央发球线和两条底线。
- [ ] 人物站立身高代理约 `1.68—1.75 m`，成人球拍约 `0.675 m`，不得为构图任意缩放任一对象。

## Seedance 视频附加检查

- [ ] 请求记录绑定 `SEEDANCE-PIPELINE-v001`、模型 ID、Prompt 哈希和素材清单。
- [ ] 所有角色参考均来自锁定角色资产或批准的动作校准图。
- [ ] 首帧、中间帧、峰值帧和末帧不存在角色融合、肢体增殖或身份跳变。
- [ ] 跨 5 秒单元续接时，上一段尾帧与下一段首帧的姿态、轴线、球路和光线成立。
- [ ] 独立镜头的并行生成没有造成服装、装备、色温或角色比例随机变化。
- [ ] 视频可解码，时长、分辨率、帧率和音轨符合批次清单。
- [ ] 除非剧情或用户明确批准，音轨中不存在背景音乐、歌曲、旋律铺底或节拍轨；默认只允许现场音效、环境声和必要对白。
- [ ] 不存在黑帧、空帧、长时间冻结、规律频闪和切点时间轴空洞。
- [ ] API 输出状态只标记为 `GENERATED`；通过本表后才可标记为 `QC-PASS`。
- [ ] 同类失败连续两次时，已停止盲目重试并回查关键帧、动作参考或 Prompt 冲突。

# 风格与角色一致性检查

每张正式图片和每个视频镜头按 100 分审核。低于 90 分不得进入正式素材区；
任一“否决项”失败时，无论总分多少都必须重做。

## 否决项

- [ ] 角色 ID、角色版本、服装版本与分镜一致；上衣、下衣资产 ID 均已填写。
- [ ] 猫科原型、耳形、毛色分区、固定毛纹和尾巴完全匹配锁定三视图。
- [ ] 惯用手、握拍、球拍和羽毛球动作正确。
- [ ] 没有复制参考作品的现有角色、服装、标志或具体镜头。
- [ ] 没有多余肢体、手指错误、尾巴穿模或角色融合。
- [ ] E3–E4 表情保留至少三个身份锚点，并存在进入帧与回弹帧。

## 评分表

| 项目 | 分值 | 检查内容 |
|---|---:|---|
| 身份一致 | 25 | 脸、眼、耳、口鼻、发型、体型 |
| 毛皮一致 | 15 | 主次毛色、白斑边界、毛纹数量与位置 |
| 服装装备 | 10 | 上衣、下衣、号码、鞋、护具、球拍、手胶 |
| 运动正确 | 15 | 重心、步法、触球点、拍面、球方向 |
| 风格一致 | 15 | 线条、平涂、硬阴影、色块、非写实程度 |
| 色彩一致 | 10 | 角色固有色、场景模式、强调色面积 |
| 镜头连续 | 10 | 轴线、屏幕方向、光源、动作衔接 |

## 喜剧表演附加检查

- [ ] 表情资产 ID、表情名称和夸张等级 E0–E4 已填写。
- [ ] 生气为 E2 左右的不爽/憋气，愤怒为 E4 爆发，两者没有混用。
- [ ] 固定额纹、脸纹、毛色分区、耳尾数量至少保留三个可见锚点。
- [ ] 夸张没有导致角色年龄、物种、惯用手或装备改变。
- [ ] E3–E4 有进入帧、峰值帧和回弹帧，峰值没有变成永久模型。
- [ ] 笑点结束后场景色彩模式和角色比例恢复。

## 镜头张力附加检查

- [ ] 机位有明确空间位置，不是抽象的“酷炫角度”。
- [ ] 透视类型、地平线、主消失点和空间线索一致。
- [ ] 至少存在两个清晰的景深层次；关键动作镜头推荐三个层次。
- [ ] 极近前景强化动作方向，没有遮住身份锚点或关键触球信息。
- [ ] 允许形变与禁止形变区域已写入分镜。
- [ ] 独特视角仍能看清球、拍、网、触球点和角色重心。
- [ ] 与上一镜的轴线、屏幕方向和球路衔接成立。

## 连续镜头对照

审核时至少并排查看：

1. 锁定三视图。
2. 上一个已通过镜头的末帧。
3. 当前镜头的首帧、中间帧、末帧。
4. 下一个镜头的预览图（若已有）。

## Seedance 视频附加检查

- [ ] 请求记录绑定 `SEEDANCE-PIPELINE-v001`、模型 ID、Prompt 哈希和素材清单。
- [ ] 所有角色参考均来自锁定角色资产或批准的动作校准图。
- [ ] 首帧、中间帧、峰值帧和末帧不存在角色融合、肢体增殖或身份跳变。
- [ ] 跨 5 秒单元续接时，上一段尾帧与下一段首帧的姿态、轴线、球路和光线成立。
- [ ] 独立镜头的并行生成没有造成服装、装备、色温或角色比例随机变化。
- [ ] 视频可解码，时长、分辨率、帧率和音轨符合批次清单。
- [ ] 不存在黑帧、空帧、长时间冻结、规律频闪和切点时间轴空洞。
- [ ] API 输出状态只标记为 `GENERATED`；通过本表后才可标记为 `QC-PASS`。
- [ ] 同类失败连续两次时，已停止盲目重试并回查关键帧、动作参考或 Prompt 冲突。

## 版本升级

只有剧情明确需要且人工审核通过时，才能升级角色或风格版本。升级后保留旧文件，
并在剧情、分镜、人物和生成记录中同步版本号，禁止覆盖历史基准。

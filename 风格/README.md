# 风格入口：NEON-SHUTTLE-CATS / 霓羽猫城

这是本项目跨对话使用的固定视觉入口。任何新对话、人物、分镜、海报或视频生成任务，
都必须先读取本文件及同目录文档，不得只凭“赛博朋克动画”几个字临时发挥。

## 一句话定义

高饱和霓虹都市中的猫科福瑞羽毛球漫画：锐利二维动画线条、硬边赛璐璐色块、
极端冷暖对撞、运动摄影般的夸张透视，以及猫科身体语言与真实羽毛球技术动作。

## 固定创作原则

1. **原创转译，不逐帧复刻。** 参考《赛博朋克：边缘行者》可观察到的高层特征，
   但不复制其角色、服装、标志、场景、构图或具体镜头。
2. **角色先于画面。** 每张图先加载锁定三视图和角色设定，再加载风格提示词。
3. **轮廓先于细节。** 缩小到缩略图时，角色仍能靠耳朵、发型、尾巴、体型和球拍辨认。
4. **动作先于特效。** 羽毛球动作必须正确，速度线和霓虹残影只能强化动作，不能遮盖它。
5. **少而准的颜色。** 单角色以 2 个主体色 + 1 个个人霓虹强调色为主。
6. **连续镜头受控。** 同一场景固定角色版本、服装版本、色温、主光方向和镜头轴线。
7. **机位必须有叙事理由。** 独特视角服务于速度、压迫、危险或战术信息，不为炫技而炫技。

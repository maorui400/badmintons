# 生成提示词库

提示词采用模块组合，不依赖单个作品名。默认使用中文结构；模型对英文理解更好时，
可使用对应英文关键词，但角色 ID、版本和不可漂移项必须保留。

## 1. 固定风格前缀

```text
NEON-SHUTTLE-CATS, STYLE-v001,
原创高能二维漫画动画，猫科福瑞羽毛球运动员，
锐利且富有粗细节奏的深墨蓝线条，硬边赛璐璐平涂，
高饱和信号色与大面积深色块形成极端冷暖对撞，
清晰角色剪影，夸张但可读的运动透视，都市科技界面作为局部视觉标点，
专业且解剖正确的羽毛球动作，停顿与爆发并存的动画关键帧感
```

推荐英文补充：

```text
original high-energy 2D comic animation, anthropomorphic feline badminton athletes,
rhythmic dark-ink line weight, hard-edged cel shading, graphic color blocking,
extreme warm-cool contrast, readable silhouettes, kinetic perspective,
selective neon rim light, accurate badminton biomechanics, expressive keyframe energy
```

## 2. 角色绑定模块

每次必须从角色设定中填充，禁止省略：

```text
[角色ID]，[角色版本]，[服装版本]，
[猫科原型]，[头身比与体型]，
[耳形与耳位]，[口鼻形状]，[眼型与虹膜色]，
[主毛色]，[次毛色及固定分区]，[固定毛纹位置和数量]，
[尾巴长度、粗细与纹样]，[发型]，[标志性细节]，
[惯用手]持拍，[球拍与手胶固定特征]，
严格匹配所附锁定三视图，保持同一身份、同一解剖、同一毛纹
```

## 3. 三视图模块

```text
正面、严格侧面、严格背面三栏角色设定图，
同一角色、同一服装、同一比例、同一中性站姿、同一镜头高度，
全身完整可见，双脚落在同一基线上，尾巴无遮挡，
中性冷雾灰纯背景，均匀白光，无透视夸张，无环境色污染，
清楚展示耳朵、毛色分区、毛纹、尾巴、球衣、球鞋和球拍细节
```

三视图负面约束：

```text
不同角色，不同年龄，不同体型，不同服装，毛纹漂移，耳形改变，
尾巴长度改变，左右镜像，惯用手切换，透视广角，动态姿势，
强烈霓虹光，复杂背景，写实毛发，3D渲染，塑料质感
```

## 4. 动作镜头模块

```text
[镜头ID]，[景别与机位]，[画面比例]，
[透视类型]，[镜头所在的具体空间位置]，[主消失点位置]，
[极近前景物]占画面[比例]，中景主体与远景参照物形成明确尺度跃迁，
[角色ID]正在执行[具体羽毛球动作阶段]，
重心位于[位置]，持拍臂[姿态]，非持拍臂[姿态]，
肩胯旋转[方向]，触球点[位置]，球头朝向飞行方向，
球拍面角度清晰，脚步与落地逻辑正确，
斜线构图，前中后景分离，局部运动形变，短促残影，
[场景色彩模式]，主光来自[方向]，角色脸部身份锚点可见
```

动作镜头不得只写“夸张透视”。至少明确：

```text
镜头位置 + 视线高度 + 镜头倾角 + 透视类型 + 主消失点 +
最近物体 + 最远参照物 + 允许形变区域 + 禁止形变区域
```

示例：

```text
镜头贴近网带、低于运动员胸口，向后场轻微仰拍，
18mm超广角的强透视感，主消失点位于画面右上三分之一处，
前景网带横切画面下缘并明显放大，中景为起跳杀球角色，
远景球场边线与灯架共同收向消失点，
允许持拍前臂、球拍框和近侧鞋产生速度性透视放大，
禁止脸部、耳朵、固定毛纹和躯干比例发生身份破坏性形变
```

## 5. 情绪近景模块

```text
猫科福瑞角色面部近景，[具体情绪]，
耳朵角度、瞳孔、胡须与嘴角共同表达情绪，
保留固定眼型、毛纹、耳缺口和口鼻比例，
单一高饱和背景色块，深色硬阴影切过面部，
一处眼部高光，一处个人霓虹强调色，漫画分镜冲击力
```

## 6. 多角色同框模块

```text
角色A固定在画面[位置]，引用[A参考图]；
角色B固定在画面[位置]，引用[B参考图]；
分别保持两者的猫科原型、耳形、毛色、毛纹、体型、服装和个人强调色，
身体不融合，尾巴不交叉穿模，球拍归属清楚，视线关系明确，
通过明度、冷暖和轮廓区分角色，不交换任何外形特征
```

## 7. 通用负面约束

```text
受参考作品现有角色、服装、标志或具体构图，
写实摄影，超写实毛发，3D塑料感，柔焦梦幻光，全局霓虹泛光，
普通人类脸加猫耳，四足宠物猫，兽化程度漂移，
角色身份漂移，脸型漂移，毛色漂移，毛纹增减或镜像，
耳朵形状改变，尾巴数量错误，尾巴穿模，左右手互换，
多余手指，多余肢体，手掌融合，错误握拍，球拍弯曲或漂浮，
羽毛球变成网球或能量球，球网结构错误，球场线错误，
不可读文字，随机标志，过量色差，过量扫描线，背景杂乱
平视站桩，中焦纪录片机位，无前中后景，随机鱼眼扭曲，
多个互相冲突的消失点，人物与场景透视不一致，纯炫技而动作不可读
```

## 8. 视频连续性尾缀

```text
与上一镜保持完全相同的角色模型、毛纹、服装、球拍、场景色温和主光方向；
动作从上一镜结束姿态自然延续；保持画面轴线、角色屏幕方向和球的飞行方向；
只改变分镜明确要求变化的项目
```

## 9. 使用顺序

完整提示词按以下顺序拼接：

`固定风格前缀 → 角色绑定 → 场景 → 动作/情绪 → 镜头 → 光色 → 连续性尾缀 → 负面约束`

不得用“更像某作品一些”作为修改指令。修改时应指出具体变量，例如：
“阴影改为硬边两级”“洋红面积从 20% 降到 5%”“透视加强但脸部不形变”。

不得在生成提示词中使用在世插画师姓名。使用 `镜头张力规范.md` 中的具体镜头变量，
把参考转译为我们自己的摄影与透视语言。

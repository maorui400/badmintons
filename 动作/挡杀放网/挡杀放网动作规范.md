# 挡杀放网动作规范

- 动作 ID：`ACTION-BLOCK-NET-v001`
- 名称：正手挡杀卸力放网
- 状态：`CURRENT / BOARD-READY`
- 适用：对方从后场杀球后，防守方以短促触球吸收来球速度，把球分到对方网前。

## 动作目标

这不是重新发力抽球，也不是大幅挥拍。核心是稳定来球方向、缩短挥拍、放松握拍并用拍面与手指完成轻柔导向，让高速杀球在过网后迅速失速。

## 六阶段

1. `P1 分腿启动`：面对来球完成小幅 split step，双脚略宽于肩，前脚掌着地，膝髋屈曲，重心居中偏前；右手球拍位于身体前方。
2. `P2 对位压低`：根据杀球落点向侧前方小跨或并步，躯干不后仰；持拍肘位于身体前侧，拍头高于手，非持拍手自然平衡。
3. `P3 短引拍`：右前臂只做极短后移，拍柄保持松握，腕关节稳定；禁止把拍头拉到身体后方。
4. `P4 卸力触球`：在身体前方、约腰至下胸高度迎球。拍面微开并朝远侧网前目标，触球瞬间前臂运动幅度很小，手指由松到稳，允许拍面沿来球方向轻微回让以吸收速度，但不得托住或持球。
5. `P5 轻柔导向`：触球后拍头只向目标方向送出短距离，球头朝远侧前场飞行；拍面角度稳定，不做甩腕大随挥。
6. `P6 回位`：球拍迅速回到身体前方，双脚恢复中立防守，视线跟随羽毛球至网带和落点。

## 滚网子弹时间

- 羽毛球必须保持真实结构：软木球头 + 羽毛裙，不得变成球体或能量弹。
- 本项目“滚网过网”默认表现为极贴网但不碰网：软木球头最低点仍高于白色网带上缘，画面中必须保留可辨识的空气间隙；羽毛裙因气流轻微颤动，越过网的垂直平面后自然翻转并下坠。
- 越网后重心落向橙超一侧前场，球头向下，羽毛裙仍在上方；不得悬停、倒飞或沿网带长距离滚动。
- 子弹时间只放慢局部 0.5—0.8 秒的真实时间，可在成片中扩展为 2—3 秒视觉时长；网带纤维、羽毛振动和球头旋转清晰，背景运动大幅降速。

## 跨机位不变量

- 铁蛋始终右手持拍，右腕黑表不得变腕；左手只辅助平衡。
- 触球点始终在身体前方，不因背后机位而镜像到左手。
- 拍面朝远侧网前落点；屏幕方向可随机位改变，但球路仍从铁蛋半场越网到橙超半场。
- 橙超杀球的上一动作服从 `ACTION-SMASH-v001`；两套动作在同一球路上连续。

## 否决项

- 大幅后摆或大随挥，把卸力挡杀做成抽球、挑球或网球挥拍。
- 手腕塌陷、拍面乱翻、触球点落在身体后方。
- 左右手交换、球拍穿体、额外手指或拍框变形。
- 羽毛球穿网、变球形、在网带上不受重力地长距离滑行。
- 软木球头撞上、压住或擦碰网带，或用网带反弹代替真实的贴网越过轨迹。
- 球越网后落回铁蛋一侧，或双方场区关系反转。

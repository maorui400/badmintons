# SHOT-001 视觉设计

概念角度：镜头不是主动炫技地后退，而是像冷漠的办公系统一样，两次切换到更远的观察距离，把清晰个体逐级压缩成工位网格中的一点。

- 画面使用项目 `STYLE-v002` 的锐利二维漫画、深墨蓝轮廓和硬边赛璐璐平涂。
- 采用 `MODE-DAY-HARSH` 冷白办公变体；电光青只用于屏幕微光。
- 焦点元素：铁蛋及其工位。
- 边缘锚点：显示器上沿、重复桌边、窗框和工位隔断。
- 支撑细节：不可读的屏幕行块、文件夹轮廓、猫科同事剪影。
- 背景处理：冷蓝灰办公室与受控景深；不得使用全局霓虹或彩色渐变。
- 不出现文字；字体仅作为工程保留项，若后续加入技术标记则使用 Inter / JetBrains Mono。
- 三段画面不使用圆角卡片、网页式容器或 UI 叠层。
